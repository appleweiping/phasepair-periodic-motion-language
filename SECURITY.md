# Security and private-data disclosures

Do not open a public issue containing credentials, download URLs, participant
identifiers, restricted data, model weights, private paths, raw experiment
outputs, or server locators. Use GitHub's private vulnerability reporting for
the repository owner instead.

If a secret or restricted byte is found in any Git object, stop publication,
rotate the affected credential where applicable, preserve an incident receipt,
and perform a separately reviewed history-remediation procedure. Deleting the
file in a later commit is not sufficient.
