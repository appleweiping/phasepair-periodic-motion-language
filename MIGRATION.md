# PhasePair v0.1.0 to PhaseSet

## Immutable ancestor

`v0.1.0` remains the exact PhasePair data-free dyadic milestone. Its annotated
tag must not be moved, replaced, deleted, or retagged. Historical PhasePair
documents and the `phasepair_core` namespace are retained so the old Morlet
kernel, directed 13D relation descriptor, swap algebra, and release checks can
be replayed.

## New identity

The repository successor is **PhaseSet**, distributed as `phaseset-core` and
imported as `phaseset_core`. The new API models a set of actors rather than
ordered `actor_a/actor_b` roles. Old PhasePair checkpoints are not compatible
with the shared-weight group backbone and are not automatically upgraded.

## Compatibility promise

- PhasePair v0.1.0 tests continue to pass unchanged.
- PhaseSet retains and regression-tests the legacy 13D field layout and
  endpoint-swap algebra. Its resampled input uses a separately hashed 20-Hz
  Morlet bank with the same physical center frequencies, so its tap bytes and
  same-array descriptor values are intentionally not claimed equal to the
  legacy 30-Hz oracle.
- For `K=2`, PhaseSet topology contributes exact positive zero and the full
  PhaseSet token path equals the PhaseSet pair-only control.
- No claim is made that the complete old role-specific two-tower model is
  bitwise equivalent to the new permutation-equivariant group model.

## Repository rename

The GitHub repository was renamed in place to
`appleweiping/phaseset-multiperson-motion-language`, retaining numeric
repository ID `1345199252`, history, main ref, annotated `v0.1.0` tag, release,
and Actions history. The former web address permanently redirects and both old
and new anonymous Git/codeload endpoints were verified after the rename. Local
clones should still update their remote explicitly. The old slug must not be
reused because doing so disables GitHub's redirect.

The public, credential-free observation is recorded in
[`docs/PHASESET_GITHUB_MIGRATION_RECEIPT.json`](docs/PHASESET_GITHUB_MIGRATION_RECEIPT.json).
It binds the numeric repository identity, immutable ancestor refs, release and
Actions identities, redirect result, and post-rename anonymous codeload bytes.
