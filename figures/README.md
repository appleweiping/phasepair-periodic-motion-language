# PhaseSet paper figures

The figure sources are data-free and contain no empirical result.

| Figure | Editable source | Publication exports | Slide version |
|---|---|---|---|
| Pair-bag incidence counterexample | `phaseset_motivation.drawio` | PDF, SVG, PNG | `phaseset_motivation.pptx` |
| PhaseSet architecture | `phaseset_architecture.drawio` | PDF, SVG, PNG | `phaseset_architecture.pptx` |

The `.drawio` files are the semantic/editable authority. PPTX files contain a
lossless full-slide rendering for convenient placement; edit the matching
draw.io source and regenerate all exports rather than manually changing one
format. Paper captions and numerical annotations must be rendered from the
frozen aggregate once real results exist.

The motivation figure deliberately constructs two four-actor complete graphs
with the same actor marginals and the same multiset of six pair tokens (two of
each relation type) but different actor–edge incidence. Pair-bag averaging is
therefore identical, while incident moments can distinguish the structures.
